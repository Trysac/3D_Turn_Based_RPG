# Credits

Everything in this repository is original work made for this project; no third-party assets
are included.

| Asset | Where | How it was made |
|---|---|---|
| Heroes, monsters, the Cinder King, scenery | `Assets/Scripts/Game` | Built at run time from Unity's primitive meshes and a cone mesh made in code (`Models.cs`, `Arena.cs`, `Shapes.cs`) |
| Materials, particle texture, scene, app icon, UI panel settings | `Assets/Art`, `Assets/Scenes`, `Assets/UI` | Generated by `Assets/Editor/ProjectBuilder.cs` |
| Music (road, battle and boss themes) and sound effects | `Assets/Audio` | Synthesized by `tools/audio` (Python standard library, encoded with ffmpeg) |
| HUD layout and style | `Assets/Scripts/Game/Hud.cs`, `Assets/UI/Hud.uss` | Written for this project (UI Toolkit) |
| Font | — | Unity's default runtime font |

## Origin and removed content

The repository started in January 2022 from the first lessons of a Zenva course on building a
3D turn-based RPG in Unity (branch `Zenva`). The `fix/asset-licensing` and `feat/rpg-campaign`
changes of 2026 removed the course-provided content because no licence file came with it:

- `Assets/Imported_Assets/Models`: the `advancedCharacter`/`basicCharacter` models with eight
  skins and their materials, and nature models (fence, grass, rocks, trees);
- `Assets/Imported_Assets/Sprites`: `CharacterSelection.png`, `Heal.png`, `Square.png`;
- the character prefabs, materials, ScriptableObject data and Battle scene built on them, the
  course character scripts, and the bundled TextMesh Pro essentials.

Those files remain in the git history, which was not rewritten.
